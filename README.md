# AI Course Laboratories

This repository contains the completed laboratory exercises for the Artificial Intelligence course. Each folder corresponds to a specific topic and includes the assignment PDF along with a Jupyter Notebook containing the implementations, answers, and reflections.

## Repository Structure

1. **Neural Models Lab (`nueral models/`)**
   - Investigates the XOR problem, the necessity of non-linear hidden layers, activation functions (Sigmoid, Tanh, ReLU), symmetry breaking, and softmax extensions.
   
2. **Agents Lab (`agents lab/`)**
   - Explores the concept of goal-based agents using a warehouse navigation problem and solving it via Breadth-First Search (BFS).
   
3. **Search Lab (`search lab/`)**
   - Deep dive into formulating search problems, and comparing the performance of un-informed search (BFS) against informed heuristic search (A*) with different distance functions.
   
4. **Logical Reasoning Lab (`logic lab/`)**
   - Combines logic and search to create a planning agent. Deals with preconditions, effects, state transitions, and an introduction to Prolog rule-based inference.
   
5. **Bayesian Networks Lab (`bn lab/`)**
   - Models simple Autoregressive Language Models using the chain rule of probability. Implements 1st and 2nd order Markov language generation using Conditional Probability Tables (CPT) and compares greedy versus probabilistic sampling.

## Usage
The code is provided within Jupyter Notebooks (`.ipynb`). To run them, ensure you have Python 3 installed along with `jupyter`, `torch`, `matplotlib`, and `numpy`.
